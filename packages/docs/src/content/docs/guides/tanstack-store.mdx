---
title: Use with TanStack Store
description: Read a TanStack Store from React with concurrent-safe transitions.
---

TanStack Store publishes whole snapshots, so mirror each one into a React
store.

## Connect the store

```ts
import { Store } from "@tanstack/store";
import { createStore } from "react-concurrent-store";

const tanstack = new Store({ query: "", page: 1 });

// With no reducer, dispatching a value replaces the state.
const store = createStore(tanstack.state);
tanstack.subscribe(() => store.dispatch(tanstack.state));
```

Keep using `tanstack.setState(...)` to update.

## Read it in a component

```tsx
import { useStore } from "react-concurrent-store";

function Page() {
  const page = useStore(store, (state) => state.page);
  return <span>Page {page}</span>;
}
```

## Selecting an object

```tsx
import { useStoreWithEqualityFn } from "react-concurrent-store/with-equality-fn";

const shallow = (a, b) =>
  Object.keys(a).length === Object.keys(b).length &&
  Object.keys(a).every((key) => Object.is(a[key], b[key]));

function SearchBar() {
  const { query, page } = useStoreWithEqualityFn(
    store,
    (state) => ({ query: state.query, page: state.page }),
    shallow,
  );

  return <Input value={query} page={page} />;
}
```

## Updating inside a transition

```tsx
startTransition(() => {
  tanstack.setState((state) => ({ ...state, query: next }));
});
```

Typing stays responsive because the transition is not downgraded to a
synchronous update.
