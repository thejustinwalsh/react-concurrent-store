## createStore

Creates a new concurrent store that can hold values or promises.

### Signatures

<Tabs>
  <TabItem label="Simple Store">
    ```tsx
    function createStore<Value>(
      initialValue: Value
    ): ReactConcurrentStore<Value, Value>
    ```
    
    Creates a store where updates replace the current value directly.
    
    **Example:**
    ```tsx
    const counterStore = createStore(0);
    counterStore.dispatch(5); // Sets value to 5
    ```
  </TabItem>
  
  <TabItem label="With Reducer (No Action)">
    ```tsx
    function createStore<Value>(
      initialValue: Value,
      reducer: (currentValue: Value) => Value
    ): ReactConcurrentStore<Value, void>
    ```
    
    Creates a store with a reducer function that doesn't accept actions.
    
    **Example:**
    ```tsx
    const incrementStore = createStore(0, (current) => current + 1);
    incrementStore.dispatch(); // Increments by 1
    ```
  </TabItem>
  
  <TabItem label="With Reducer and Actions">
    ```tsx
    function createStore<Value, Action>(
      initialValue: Value,
      reducer: (currentValue: Value, action: Action) => Value
    ): ReactConcurrentStore<Value, Action>
    ```
    
    Creates a store with a reducer function that accepts actions.
    
    **Example:**
    ```tsx
    type CounterAction = { type: 'increment' } | { type: 'decrement' } | { type: 'set'; value: number };
    
    const counterStore = createStore(0, (current, action: CounterAction) => {
      switch (action.type) {
        case 'increment': return current + 1;
        case 'decrement': return current - 1;
        case 'set': return action.value;
      }
    });
    
    counterStore.dispatch({ type: 'increment' });
    counterStore.dispatch({ type: 'set', value: 10 });
    ```
  </TabItem>
</Tabs>

### Parameters

- **`initialValue`**: The initial value or promise for the store
- **`reducer`** _(optional)_: A function that determines how the store value should be updated

### Returns

A `ReactConcurrentStore` object with a `dispatch` method for updating the store.

## useStore

A React hook that subscribes to a store and returns its current value.

### Signature

```tsx
function useStore<S>(store: ReactConcurrentStore<S, A>): S;
function useStore<S, T>(
  store: ReactConcurrentStore<S, A>,
  selector: (state: S, previous: T | undefined) => T,
): T;
```

### Parameters

- **`store`**: A store created with `createStore`
- **`selector`** _(optional)_: Narrows the state to a slice. It receives the
  current state and its own previous result; returning that previous value
  unchanged tells `useStore` nothing has changed and skips the render.

### Equality functions

`useStore` takes no equality function, the same way React ships
`useSyncExternalStore` without one. Returning the previous result from a
selector is the built-in mechanism, and an equality-function wrapper is
provided from its own entry point so it costs nothing unless imported:

```tsx
import { useStoreWithEqualityFn } from "react-concurrent-store/with-equality-fn";

const slice = useStoreWithEqualityFn(
  store,
  (state) => ({ id: state.id, name: state.name }),
  shallowEqual,
);
```

### Returns

The current value of the store. If the store contains a promise, the component will suspend until the promise resolves.

### Example

```tsx
function UserProfile() {
  const userPromise = useStore(userStore);
  const user = use(userPromise); // Will suspend if promise is pending

  return <h1>{user.name}</h1>;
}
```

## ReactConcurrentStore

The store object returned by `createStore`.

### Type Definition

```tsx
type ReactConcurrentStore<S, A> = {
  getState(): S;
  dispatch(action: A): void;
  subscribe(callback: (action: A) => void): () => void;
};
```

### Methods

#### `dispatch(action)`

Updates the store's value. The behavior depends on how the store was created:

- **No reducer**: the action is either a replacement value or an updater,
  `(previous) => next`, like `useState`'s setter
- **With a reducer**: the reducer is called with the current value and the action

#### `getState()`

Returns the current value. For reading outside React — components should use
`useStore`.

#### `subscribe(callback)`

Calls `callback` after each update with the action that caused it, and returns
an unsubscribe function. This is what lets an external store stay in step
without exposing its reducer.

The store has applied the action by the time the callback runs, so `getState()`
inside it reports the state that action produced:

```tsx
store.subscribe(() => {
  persist(store.getState()); // the state including the action just dispatched
});
```

That guarantee is what lets this pair drive `useSyncExternalStore` directly,
which is the way to read a store urgently while everything else is waiting on a
transition:

```tsx
// Updates at the caller's priority rather than waiting for a pending
// transition. That is a deliberate divergence from the rest of the tree —
// this reader has opted out of the transition, the way useDeferredValue opts
// into lagging behind one.
const value = useSyncExternalStore(store.subscribe, store.getState);
```

Note that `getState()` reports the chronological state — every action in
dispatch order — not what the tree is currently showing. Inside components,
`useStore` is what shows what the tree shows.

**Parameters:**

- **`action`**: The new value or action to apply to the store

**Example:**

```tsx
// Simple store
const simpleStore = createStore("hello");
simpleStore.dispatch("world"); // Value becomes "world"

// Store with reducer
const counterStore = createStore(
  0,
  (current, action: number) => current + action,
);
counterStore.dispatch(5); // Adds 5 to current value
```

## Working with Promises

Stores can hold promises, making them perfect for async data management:

```tsx
// Create a store with a promise
const fetchUser = async (id: number) => {
  const response = await fetch(`/api/users/${id}`);
  return response.json();
};

const userStore = createStore(fetchUser(1));

function UserProfile() {
  const userPromise = useStore(userStore);
  const user = use(userPromise); // Suspends until resolved

  const loadUser = (id: number) => {
    userStore.dispatch(fetchUser(id)); // Update with new promise
  };

  return (
    <div>
      <h1>{user.name}</h1>
      <button onClick={() => loadUser(user.id + 1)}>Next User</button>
    </div>
  );
}

// Wrap in Suspense to handle loading states
function App() {
  return (
    <Suspense fallback={<div>Loading...</div>}>
      <UserProfile />
    </Suspense>
  );
}
```

## Integration with React Concurrent Features

### Transitions

Use `useTransition` to update stores without blocking the UI:

```tsx
import { useTransition } from "react";

function UserProfile() {
  const userPromise = useStore(userStore);
  const user = use(userPromise);
  const [isPending, startTransition] = useTransition();

  const handleUpdate = () => {
    startTransition(() => {
      userStore.dispatch(fetchUser(user.id + 1));
    });
  };

  return (
    <div style={{ opacity: isPending ? 0.5 : 1 }}>
      <h1>{user.name}</h1>
      <button onClick={handleUpdate}>Next User</button>
    </div>
  );
}
```

### Error Boundaries

Stores work seamlessly with Error Boundaries for error handling:

```tsx
class ErrorBoundary extends React.Component {
  constructor(props) {
    super(props);
    this.state = { hasError: false };
  }

  static getDerivedStateFromError(error) {
    return { hasError: true };
  }

  render() {
    if (this.state.hasError) {
      return <h1>Something went wrong.</h1>;
    }
    return this.props.children;
  }
}

function App() {
  return (
    <ErrorBoundary>
      <Suspense fallback={<div>Loading...</div>}>
        <UserProfile />
      </Suspense>
    </ErrorBoundary>
  );
}
```

## TypeScript Support

React Concurrent Store is written in TypeScript and provides full type safety:

```tsx
// Typed store
type User = { id: number; name: string; email: string };
const userStore = createStore<Promise<User>>(fetchUser(1));

// Typed actions
type Action =
  | { type: "increment" }
  | { type: "decrement" }
  | { type: "set"; value: number };

const counterStore = createStore(0, (state: number, action: Action): number => {
  switch (action.type) {
    case "increment":
      return state + 1;
    case "decrement":
      return state - 1;
    case "set":
      return action.value;
  }
});
```
