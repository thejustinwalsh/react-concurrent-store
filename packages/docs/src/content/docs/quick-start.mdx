A userland implementation of the `createStore` / `useStore` API proposed in
[React RFC #35449](https://github.com/facebook/react/issues/35449). Works on
React 19 and up, with no experimental React build.

     </TabItem>

2. **Import the hooks**

   ```tsx
   import { createStore, useStore } from "react-concurrent-store";
   ```

3. **Create your first store**

   ```tsx
   // Create a simple store with initial data
   const counterStore = createStore(0);

   // Or create a store with async data
   const fetchUser = async (id: number) => {
     const response = await fetch(`/api/users/${id}`);
     return response.json();
   };

   const userStore = createStore(fetchUser(1));
   ```

4. **Use the store in your components**

   ```tsx
   import { Suspense, use } from "react";

   function Counter() {
     const count = useStore(counterStore);

     return (
       <div>
         <p>Count: {count}</p>
         <button onClick={() => counterStore.dispatch(count + 1)}>
           Increment
         </button>
       </div>
     );
   }

   function UserProfile() {
     const userPromise = useStore(userStore);
     const user = use(userPromise); // Suspend until resolved

     return (
       <div>
         <h1>{user.name}</h1>
         <p>{user.email}</p>
       </div>
     );
   }

   function App() {
     return (
       <div>
         <Counter />
         <Suspense fallback={<div>Loading user...</div>}>
           <UserProfile />
         </Suspense>
       </div>
     );
   }
   ```

</Steps>

## Urgency is per dispatch

A dispatch inside `startTransition` is one the tree does not have to show yet.
A dispatch outside one has to be visible now, and lands on what is on screen
rather than on the state the transition is still waiting for.

```tsx
// Slow: the old screen stays up until this is ready.
startTransition(() => store.dispatch({ type: "navigate", to: "/profile" }));

// Urgent: visible immediately, on the page they are still looking at.
store.dispatch({ type: "like" });
```

Nothing else tells the store which is which — see
[Rebasing](/react-concurrent-store/explanation/rebasing/).
